# Food Delivery Waiting Time Analysis - Project 2

Intermediate Data Analysis focusing on Cleaning and Visualization.

### Dataset
- File: synthetic_fooddelivery_dataset.csv
- Columns: Jarak_Kirim_KM (Distance), Waktu_Tunggu_Menit (Waiting Time), Kategori_Menu (Menu Category), Tingkat_Keluhan (Complaint Level)

### What I Did
- Data Cleaning: Used dropna() to remove nulls
- EDA: Used describe(), groupby(), mean()
- Visualizations: Boxplot, Barplot, Heatmap

### Key Findings
1. Average Waiting Time: 32 mins
2. Slowest Menu Category: Heavy meals
3. High Complaint = Higher Waiting Time
4. Distance vs Time Correlation: 0.75
5. Cleaning is important for accurate results

Python, Pandas, Seaborn, Matplotlib, Google Colab
